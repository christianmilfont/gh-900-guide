## Comandos iniciais
 *criação e inserção de arquivos*: Formatação Linux
 ```bash
    mkdir NOME-DO-ARQUIVO
    cd NOME-DO-ARQUIVO
 ```

*iniciar git e adicionar a branch*:
 ```bash
    git init
    git branch -M main
 ```

 (*comandos extras para login no CLI*):
 ```bash
    git config --global user.name "Seu Nome"
    git config --global user.email "seu-email@example.com"
```
